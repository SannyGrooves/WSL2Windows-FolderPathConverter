# WSL2Windows-FolderPathConverter
Path converter for folder adres from Windows to WSL2 Linux for AI or research purpose.

WARNING!
DONT SCAN COMPLETE c: DRIVE OR OTHER SYSTEM DRIVES, APP WILL CRASH! IT WILL SCAN ALL FOLDER PATHS AND STORES IT ONTO RAM TEMP.
